Núcleo del Juego

Frontend
HTML5 Semántico + CSS3 Puro

Interfaz visual inspirada en terminales de admisión retro (*Papers, Please*). Diseñado sin frameworks pesados para un rendimiento de 60fps en cualquier móvil.

Motor Lógico

Lógica
JavaScript Vanilla (ES6+)

Algoritmos de generación procedural de enunciados proposicionales, resolución de tablas de verdad, inferencias modus ponens/tollens y feedback pedagógico inmediato.

Contenedor Nativo

Móvil
Capacitor 8.5 + Gradle

Empaqueta la web local en una aplicación autónoma de Android instalable (`app-debug.apk`), puenteando eventos de ciclo de vida del dispositivo móvil.

Sincronización Offline

Resiliencia
LocalStorage (Web Storage API)

Genera un UUID persistente para cada inspector y mantiene una cola local de partidas en caso de pérdida de señal, subiéndolas al reconectar.

Servidor Unificado

Backend
Node.js + Express.js

Servidor de alto rendimiento que centraliza la API REST y sirve los archivos estáticos del panel de control bajo un solo puerto para Render.

Base de Datos Cloud

Persistencia
PostgreSQL 15 (Supabase Cloud)

Instancia administrada en AWS con integridad referencial, índices de aceleración para rankings y claves foráneas en cascada con SSL obligatorio.

Panel de Supervisión

Analytics
Chart.js + Glassmorphism

Dashboard interactivo para que docentes y supervisores monitoreen en vivo los promedios de puntaje, precisión global y podio de inspectores.

Infraestructura Nube

Despliegue
Render.com Web Service

Hospedaje continuo integrado con GitHub, asignación dinámica de puertos y certificados SSL automáticos sin costo.
